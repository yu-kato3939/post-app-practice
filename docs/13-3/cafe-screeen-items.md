#メニュー画面の画面項目定義

| 項目名               | 種類   | 必須 | 内容                                                 |
| :------------------- | :----- | :--- | :--------------------------------------------------- |
| 画面見出し           | 表示   | -    | メニュー                                             |
| 区分見出し           | 表示   | -    | ドリンクorフード                                     |
| 商品名               | 表示   | -    | その日に出す商品名                                   |
| 値段                 | 表示   | -    | その商品の値段                                       |
| 説明                 | 表示   | -    | その商品に対する説明                                 |
| 個数                 | 選択   | 必須 | 注文する商品の個数の選択。売り切れの商品では選べない |
| カートに入れるボタン | ボタン | -    | 押すとカート画面へ移動。売り切れの時は押せない       |
| 注文状況             | リンク | -    | 押すと注文状況へ移動する                             |
