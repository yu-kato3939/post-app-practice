##エラーレスポンス一覧

| 起こること                                   | ステータスコード | 返すもの                 |
| :------------------------------------------- | :--------------- | :----------------------- |
| ログインしていない                           | 401              | ログインが必要           |
| 送ったものに不備がある時                     | 422              | 不備のあった項目について |
| 投稿が存在していない（取得・書き換え・削除） | 404              | 見つからない旨           |
| 自分の投稿でない（取得・書き換え・削除）     | 403              | 権限がない               |
