#### API-03　投稿一件を書き換えるの詳細

-- **メソッドとエンドポイント**:PUT|/api/posts/{id}
-- **認証**:必要
-- **送るもの**:本文（必須）、タイトル（必須、255文字以内）、カテゴリの番号（必須、登録済みのカテゴリ）
-- **返すもの（うまくいったとき）**:200。書き換えたあとの投稿1件（投稿の番号・タイトル・本文・カテゴリの番号・投稿者の番号・登録日時・更新日時）
-- **返すもの（うまくいかなかったとき）**:401（ログインしていない時）/422（送ったものに不備あり）/404（存在していない時）/403（自分の投稿ではない時）
