##　エンドポイント一覧

| ID     | メソッド | エンドポイント         | 何をするか               | 認証 |
| :----- | :------- | :--------------------- | :----------------------- | :--- |
| API-01 | GET      | /api/products          | 商品一覧の取得           | 不要 |
| API-02 | PUT      | /api/orders            | 商品を登録する           | 不要 |
| API-03 | GET      | /api/orders/{注文番号} | 一件あたりの注文状況     | 不要 |
| API-04 | DELETE   | /api/orders/{注文番号} | 注文を取り消す           | 不要 |
| API-05 | GET      | /api/orders            | 受け取り前の注文を取得   | 必要 |
| API-06 | PUT      | /api/orders/{注文番号} | 注文を受け渡し済みにする | 必要 |

## 一本ごとの詳細

###### API-02:注文を登録する

--##メソッドとエンドポイント##:PUT /api/orders
--##認証##:不要
--##送るもの##:本文で、注文する商品と個数の組（1組以上。個数は一つの商品あたり10個まで）
--##返すもの（上手くいった時）##:201。注文番号と合計金額、支払いの手続き
--##返すもの（上手くいかなかった時）##:422(送った内容に不備がある時)

###### API-06:受け渡し済み処理

--##メソッドとエンドポイント##:PUT /api/orders/{注文番号}
--##認証##:必要
--##送るもの##:受け渡し済みにすること
--##返すもの（上手くいった時）##:200。受け渡し済みの処理が完了
--##返すもの（上手くいかなかった時）##:401（ログインしていない）/404（注文番号がない）

## エラーレスポンス一覧

| 起こること                                         | ステータスコード | 返すコード                     |
| :------------------------------------------------- | :--------------- | :----------------------------- |
| 送ったものに不備がある（注文の登録）               | 422              | 不備の項目に対する理由         |
| 売り切れの商品が注文された（注文の登録）           | 422              | 売り切れです                   |
| 注文番号が見つからない（お客様の確認、取り消し時） | 404              | 注文番号の商品が見つかりません |
| 注文番号が見つからない（店員の受け渡し時）         | 404              | 注文番号の商品が見つかりません |
| ログインしていない（店員用）                       | 401              | ログインが必要です             |
