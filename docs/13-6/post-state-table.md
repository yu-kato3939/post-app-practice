##　状態変異表

遷移表

| 今の状態 | 起きること   | 次の状態 | 条件 |
| :------- | :----------- | :------- | :--- |
| 投稿なし | 登録         | 公開中   | -    |
| 公開中   | 公開をやめる | 非公開   | -    |
| 非公開   | 後悔する     | 公開中   | -    |

増える設計

| 足すもの                                   | どの設計に増えるのか     |
| :----------------------------------------- | :----------------------- |
| 投稿の状態                                 | テーブル定義書           |
| 「投稿の公開をやめる」「もう一度公開する」 | 機能一覧                 |
| 上記機能のボタン                           | 画面項目、フレームワーク |
| 非公開投稿は投稿者にのみ見れる             | 権限マトリクス           |
