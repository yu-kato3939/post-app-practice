## 例外一覧

| 起きること                           | どこで気づくか           | その時の処理   | 利用者へのお知らせ       |
| :----------------------------------- | :----------------------- | :------------- | :----------------------- |
| ログインしていない人が投稿一覧を開く | 投稿一覧画面を非ラック時 | やめて元に戻す | ログインしてください     |
| 他人の投稿を編集しようとしている     | 編集する時               | やめて元に戻す | 編集できません           |
| タイトル、本文に不備がある           | 入力を確認するとき       | やめて元に戻る | どこに不備があるのか     |
| 存在しないカテゴリを選択             | 入力を確認するとき       | やめて元に戻る | カテゴリが存在しません   |
| １分間で6回以上のログインを試した    | ログイン確認             | やめて元に戻る | ログイン超過             |
| 時間超過で強制ログアウト             | 画面を開くとき           | やめて元に戻る | ログインし直してください |
