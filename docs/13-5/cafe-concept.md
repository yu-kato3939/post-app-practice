## エンティティ一覧

| エンティティ | 何を覚えておくものか     | 主な属性                                                       |
| :----------- | :----------------------- | :------------------------------------------------------------- |
| 商品         | その日のドリンクとフード | 商品名・値段・説明・ドリンクかフードか・その日に販売可能か否か |
| 注文         | お客様が1回で出した注文  | 注文番号・合計金額・ 受け取り状況                              |
| 注文詳細     | 注文の中の商品1種類分    | 個数・注文した時の値段                                         |

## 関係一覧

| エンティティA | 関係  | エンティティB | 読み方                               |
| :------------ | :---- | :------------ | :----------------------------------- |
| 注文          | 1対多 | 注文詳細      | 1件の注文は、1つ以上の注文詳細を持つ |
| 商品          | 1対多 | 注文詳細      | 1つの商品は、複数の注文詳細に出る    |
