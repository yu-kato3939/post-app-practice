## CRUD表

| 機能         | ユーザー | 投稿 | カテゴリ |
| :----------- | :------- | :--- | :------- |
| ユーザー登録 | C        |      |          |
| ログイン     | R        |      |          |
| ログアウト   |          |      |          |
| 投稿一覧表示 | R        | R    | R        |
| 投稿の編集   |          | R・U | R        |
| 投稿の削除   |          | D    |          |

投稿の列にはCがありません。投稿を書く機能がないです。
カテゴリの列にもCがないため、データを読むだけになっています。
ログアウトはデータに何も触れない機能になっています。
