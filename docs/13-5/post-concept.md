## エンティティ一覧

| エンティティ | 何を覚えておくものか | 主な属性                         |
| :----------- | :------------------- | :------------------------------- |
| ユーザー     | アプリを使う人       | 名前・メールアドレス・パスワード |
| 投稿         | 書き込まれた投稿     | タイトル・トピック・本文         |
| カテゴリ     | 投稿に対するカテゴリ | カテゴリ                         |

## 関係の一覧

| エンティティA | 関係  | エンティティB | 読み方                             |
| :------------ | :---- | :------------ | :--------------------------------- |
| ユーザー      | 1対多 | 投稿          | 一人のユーザーは複数の投稿をする   |
| カテゴリ      | 1対多 | 投稿          | 一つのカテゴリには複数の投稿がある |
