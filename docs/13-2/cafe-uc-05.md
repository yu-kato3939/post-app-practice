#### UC-05: {動詞で終わるユースケース名}

- **アクター**: 店員
- **事前条件**: 受け取り前の注文が一件以上ある
- **基本フロー**:
    1. 店員が注文一覧画面を開く
    2. システムが受け取り前の注文を注文番号とともに一覧で表示する
    3. 店員がお客様から伝えられた注文番号を選ぶ
    4. システムが注文の商品と個数を表示する
    5. 店員が商品を渡し、「受け渡し済み」を押す
    6. システムが受け渡し済みとして受け取り一覧から外す
- **代替フロー**:
    - 3a. 注文番号がない場合、注文番号がないことをシステムが表示
- **事後条件**: 注文が受け渡し済みとして記録され、受け取り前の一覧に表示されなくなる
- **受け入れ条件**:
    - [ ] 注文一覧画面に受け取り前の注文が注文番号とともに表示される
    - [ ] 注文番号で注文を選ぶと、商品と個数を表示する
    - [ ] 「受け渡し済みにする」を押すと、注文が受け渡し前の一覧から消える
