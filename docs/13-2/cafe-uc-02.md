#### UC-02: {動詞で終わるユースケース名}

- **アクター**: お客様
- **事前条件**: なし
- **基本フロー**:
    1. お客様がメニュー画面で商品と個数を選び、「カートに入れる」を押す。
    2. システムが注文内容と合計金額を表示する
    3. お客様が「お支払いに進む」を押す
    4. システムが支払いの画面を表示する
    5. お客様が支払いをする
    6. システムが注文を登録して注文画面を表示する
- **代替フロー**:
    - 5a. 支払いが完了できなかった場合、エラーの表示をし、注文を登録しない
- **事後条件**: 注文が一件登録され、発行された注文番号で注文状況を確認できる
- **受け入れ条件**:
    - [ ] メニュー画面で商品と個数を選ぶと、注文内容と合計金額が表示される
    - [ ] 支払いが完了すると注文番号が表示される
    - [ ] 支払いが完了しないまま終わると、エラー表示、注文は登録されない
