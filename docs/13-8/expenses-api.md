## エンドポイント一覧

| ID     | メソッド | エンドポイント           | 何をするか             | 認証 |
| :----- | :------- | :----------------------- | :--------------------- | :--- |
| API-01 | POST     | /api/expenses            | 経費申請を一件提出する | 必要 |
| API-02 | GET      | /api/expenses            | 申請一覧を取得する     | 必要 |
| API-03 | GET      | /api/expenses/{申請のid} | 申請一件を取得         | 必要 |
| API-04 | PUT      | /api/expenses/{申請のid} | 申請一件の書き換え     | 必要 |

## 詳細

#### API-01:申請を一件提出する

- **メソッドとエンドポイント**:POST /api/expenses
- **認証**:必要
- **送るもの**:本文で、使った日、金額、用途、費目
- **返すもの（うまくいったとき）**:201。登録した申請一件（id、使った日、金額、用途、費目、状態）
- **返すもの（うまくいかなかったとき）**:401（ログインしていないとき）/422(送ったものに不備)

#### API-04:申請を書き換える

- **メソッドとエンドポイント**:PUT /api/expenses/{申請のid}
- **認証**:必要
- **送るもの**:URLに申請のid、本文で、申請者が書き直した中身（使った日、金額、費目、用途）、承認者が判断するときは承認か差し戻し、差し戻しの際は理由
- **返すもの（うまくいったとき）**:200。書き換えた申請1件（id、使った日、金額、費目、用途、状態、差し戻しの理由）
- **返すもの（うまくいかなかったとき）**:401（ログインしていないとき）/422（送ったものに不備）（申請中でない申請を判断しようとした）/403（自分に関わりがない申請）/404（申請が見つからない）

## エラーレスポンス一覧

| 起こること                                             | ステータスコード | 返すもの                       |
| :----------------------------------------------------- | :--------------- | :----------------------------- |
| ログインしていない                                     | 401              | ログインが必要                 |
| 自分に関係がない申請を見ようとした、書き換えようとした | 403              | 権限がない                     |
| idが見つからない                                       | 404              | 指定のidのものが見つかりません |
| 送ったものに不備(提出・書き換える)                     | 422              | 不備のある項目を表示           |
| 申請中でない申請を承認または差し戻そうとした           | 422              | 申請中ではない                 |
