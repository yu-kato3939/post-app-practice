## 権限マトリクス

| 機能                 | 申請者 | 承認者 | ログインしていない相手 |
| :------------------- | :----- | :----- | :--------------------- |
| F-01申請書の提出     | ⚪︎     | ⚪︎     | ×                      |
| F-02申請書の状況     | △      | △      | ×                      |
| F-03申請書の承認     | ×      | △      | ×                      |
| F-04申請書の差し戻し | ×      | △      | ×                      |
| F-05申請書の書き直し | △      | △      | ×                      |

△の条件は以下の通りです。
・F-02(申請者、承認者)：自分の申請だけ、承認者はこれに加え、自分宛の申請書
・F-03,F-04(承認者)：自分宛の申請書のみ
・F-05(申請者、承認者)：自分が出した申請書が差し戻された申請書だけ
