## 作らないもの

| 作らないもの                             | 理由                                   |
| :--------------------------------------- | :------------------------------------- |
| 領収書の写真貼り付け                     | 相談内容にて今は大丈夫とのことなため   |
| 振り込みの手続きや会計ソフトへの振り込み | 相談内容にて依頼者が行うとのことなため |
