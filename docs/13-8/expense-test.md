## テスト設計

| ID     | なにを確かめるのか                                                                 | 区分   | 元になった設計書                          |
| :----- | :--------------------------------------------------------------------------------- | :----- | :---------------------------------------- |
| TC-001 | 社員が立替日・金額・用途・費目を入力して経費申請できること                         | 正常系 | 要件定義書、API設計書（API-01）           |
| TC-002 | 申請登録後、申請ID・入力内容・状態が正しく返されること                             | 正常系 | API設計書（API-01）                       |
| TC-003 | 交通費・書籍代・会議費・その他の4種類の費目を選択して申請できること                | 正常系 | 要件定義書、テーブル定義書                |
| TC-004 | 社員が自分の申請一覧を取得できること                                               | 正常系 | 要件定義書、API設計書（API-02）           |
| TC-005 | 承認者が自分のところに出ている申請一覧を取得できること                             | 正常系 | 要件定義書、API設計書（API-02）           |
| TC-006 | 指定した申請IDの申請内容を取得できること                                           | 正常系 | API設計書（API-03）                       |
| TC-007 | 申請中の申請を承認すると、状態が承認済みに変わること                               | 正常系 | 遷移図、API設計書（API-04）               |
| TC-008 | 申請中の申請を差し戻せること                                                       | 正常系 | 遷移図、API設計書（API-04）               |
| TC-009 | 差し戻し理由が正しく保存されること                                                 | 正常系 | 例外一覧、テーブル定義書                  |
| TC-010 | 差し戻された申請を申請者本人が修正して再提出できること                             | 正常系 | 遷移図、API設計書（API-04）               |
| TC-011 | 必須項目を入力せずに申請した場合、申請できないこと                                 | 異常系 | API設計書（API-01）、エラーレスポンス一覧 |
| TC-012 | 不正な費目を指定した場合、申請できないこと                                         | 異常系 | テーブル定義書、API設計書（API-01）       |
| TC-013 | ログインしていない状態では経費申請できないこと                                     | 異常系 | API設計書（API-01）、エラーレスポンス一覧 |
| TC-014 | 存在しない申請IDを指定した場合、申請を取得できないこと                             | 異常系 | API設計書（API-03）、エラーレスポンス一覧 |
| TC-015 | 申請中ではない申請を再度承認・差し戻しできないこと                                 | 異常系 | API設計書（API-04）、エラーレスポンス一覧 |
| TC-016 | 申請の書き換えに失敗した場合、書きかけの内容が保存されず、元の内容が維持されること | 異常系 | 例外一覧                                  |
| TC-017 | 金額に50,000円を入力して申請できること                                             | 境界値 | 要件定義書                                |
| TC-018 | 金額に50,001円を入力すると申請できないこと                                         | 境界値 | 要件定義書                                |
| TC-019 | 用途に100文字を入力して申請できること                                              | 境界値 | テーブル定義書                            |
| TC-020 | 用途に101文字を入力すると申請できないこと                                          | 境界値 | テーブル定義書                            |
| TC-021 | 差し戻し理由に200文字を入力できること                                              | 境界値 | テーブル定義書                            |
| TC-022 | 差し戻し理由に201文字を入力すると差し戻せないこと                                  | 境界値 | テーブル定義書                            |
