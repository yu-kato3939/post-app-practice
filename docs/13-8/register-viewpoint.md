## 新規登録のテスト設計

| ID    | 何を確かめるのか                                   | 区分   | 元になった設計書  |
| :---- | :------------------------------------------------- | :----- | :---------------- |
| TC-01 | ログインしていなくともトップページが開ける         | 正常系 | 画面一覧の設計書  |
| TC-02 | 名前・メールアドレス・パスワードを入れて登録できる | 正常系 | CreateNewUser.php |
| TC-03 | 名前を空欄のまま登録するとできない                 | 異常系 | CreateNewUser.php |
| TC-04 | 名前が255文字なら登録できる                        | 境界系 | CreateNewUser.php |
| TC-05 | 名前が256文字では登録ができない                    | 異常系 | CreateNewUser.php |
| TC-06 | メールアドレスが既にある                           | 異常系 | CreateNewUser.php |
| TC-07 | メールアドレスの形になっていない                   | 異常系 | CreateNewUser.php |
| TC-08 | パスワードと確認用が食い違うと登録できない         | 異常系 | CreateNewUser.php |

メールアドレスと名前は何文字入れるかは決まっていない。現状は、テーブルに入る最大の255文字としている。
