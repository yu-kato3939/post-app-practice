## 画面項目定義

| 項目名       | 種類       | 必須 | 内容                                       |
| :----------- | :--------- | :--- | :----------------------------------------- |
| 画面項目     | 表示       | -    | 申請書を作成する                           |
| 使った日     | 入力(１行) | 必須 | 立て替えた日付                             |
| 金額         | 入力(１行) | 必須 | 立て替えた金額                             |
| 費目         | 選択       | 必須 | 交通費・書籍費・会議費・その他から選択する |
| 用途         | 入力(2行)  | 必須 | 何に使ったか                               |
| 差し戻し理由 | 表示       | -    | 差し戻された申請書を書き直す際に表示       |
| 提出ボタン   | ボタン     | -    | 申請一覧画面へ移動                         |
| やめるボタン | ボタン     | -    | 申請一覧へ移動                             |
